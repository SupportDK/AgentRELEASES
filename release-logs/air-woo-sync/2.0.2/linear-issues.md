## AWS-138 — Fix error update
Type: Bug · https://linear.app/wp-connect/issue/AWS-138/fix-error-update

The plugin's EDD update checker sent slug `air-wp-sync` (derived from the main filename), colliding with Air WP Sync Pro+/Free on the wpconnect update server; WordPress offered a Pro+ 2.9.x update that replaced the plugin. Fixed by sending the unique slug `air-wp-sync-for-woocommerce`.
